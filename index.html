如何安装

  1. 用 iPad 的 Safari 打开本页
  2. 点击「在 iPad 上安装 SwiftSign」
  3. 系统自动下载并安装（证书已内置签名）
  4. 首次到 设置 → 通用 → 描述文件 信任证书

常见问题

为什么下载的是未签名安装包？

这是 iOS 系统的安全机制：任何 App 安装前都必须有 Apple 证书签名。云端只负责把真实可用的程序编译出来，签名这一步需要你的证书来完成，这样才安全、可信。

SwiftSign 是基于什么做的？

基于开源引擎 Feather 构建，通过 GitHub Actions 云端编译。源码在仓库里完全公开，欢迎查看。

签名后提示「无法验证」怎么办？

请检查你的证书是否被吊销或过期，更换有效证书后重新签名即可。
